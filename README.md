# 🎮 Assembly: Endgame

A simple web game built with **React + Vite** and deployed on **Github**.  
It showcases my skills, and knowledge gained from learning **React.js** from freeCodeCamp.

---

## ✨ Features
- Start and generate random word  
- Display game messages depending on game won or lost. 
- Show confetti when the player won the game.
